# 动效规范

- Fast `140ms`：Hover、Pressed、开关和小范围颜色反馈。
- Normal `180ms`：菜单、通知、任务面板和小型内容切换。
- Slow `240ms`：对话框进入与页面级状态切换，仅在确有层级变化时使用。
- 统一缓动为 `cubic-bezier(0.23, 1, 0.32, 1)`；退出可缩短到进入时长的 80%。
- 位移距离不超过 4px，不对正文使用缩放，不使用弹簧、持续漂浮或无意义循环。
- 加载旋转是唯一允许持续运行的基础动效，并在减少动态效果时停止旋转。
- 周额度胶囊是高频组件，不使用常驻动画；Hover/Pressed 为 `140ms`，详情面板从胶囊方向进入 `180ms`、退出 `120ms`，只过渡 `transform` 与 `opacity`。
- 深色渐变桌面背景属于 Gallery 展示场景，不进入 Quiet Workspace 核心 Token。
