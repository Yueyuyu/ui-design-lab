# 用静谧工作台延伸新设计

## 设计不变量

- 以长时间阅读和清楚完成任务为目标：先用字阶、间距和细线组织信息，再考虑增加卡片。
- 配色从 tokens.json 的 color.surface、color.text、color.brand、color.status 取语义值，经 token-bindings.json 找到 CSS 变量。纸面承载内容，鼠尾草色用于主要动作；成功、运行、注意状态不能当装饰色。
- 使用本套 Windows/中文字体与 4px 间距阶梯；密度改变控件、行高和留白，不继续缩小关键文字。正文、标签与辅助字遵循现有字阶及对比度约束。
- 配额是单一连续值，任务是多个类别状态；不要为了“统一”把它们都改成同一种带点胶囊。

## 按任务选布局

| 用户任务 | 推导方式 |
| --- | --- |
| 连续写作、阅读、说明页 | 居中阅读列，局部工具靠近正文；没有层级资料时不添加资料树 |
| 周计划、复盘、设置 | 顶部分组或标签，时间/状态摘要在前，任务与说明顺序展开 |
| 需要反复切换层级资料 | 增加资料导航与正文分区；窄屏用可打开的导航，保留返回上下文 |

## 新组件的推导

以“预约时段选择器”为例，这是可由业务项目新增的组件，并非当前库导出。

1. 定义日期、可用时段、选中值、禁用原因与 onChange；预约服务由业务方提供。
2. 优先组合现有日期/选择/按钮能力；仅为时段排列新增项目组件，沿用本套控件高度、圆角、焦点和选中表面。
3. 层级为日期标题 → 时段选项 → 辅助说明。空档、加载、错误都留在原位置，错误提供重新读取；不把请求失败显示成“没有时段”。
4. 选择与提交分开，键盘能到达时段并读出不可用原因。窄屏按日期顺序排列，保留选择。

## 跨业务示例

个人课程网站可以采用顶部课程分类与阅读正文；项目复盘可用横向报告与任务清单。两者继承温暖纸面、字阶和轻量反馈，无需复制研究工作台。

## 验收

新页面要能解释主内容轴、语义颜色和密度选择。组件检查七态、键盘、中文长文本与窄屏；本地新增组件使用项目名称及样式类，不冒充 Quiet* 包导出。原有导出与能力边界仍以 API.md 和类型为准。
