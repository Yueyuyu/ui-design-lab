# 可访问性规范

- UI 辅助文字最小为 11px，控件标签和关键紧凑信息最小为 12px，正文默认 14px。
- 普通文字与背景的对比度不得低于 4.5:1；大号文字不得低于 3:1。
- 禁用状态虽然不计入 WCAG 文本对比度要求，仍要保留可辨认的标签与原因。
- 键盘焦点统一使用 3px 鼠尾草绿外环，并保留 2px 间隔。
- 舒适密度控件高度为 40px，紧凑密度为 32px；触控环境应额外扩大命中区到 44px。
- 仅当 Windows 桌面宿主提供固定 26px 工具栏槽位时，额度胶囊可使用 26px 视觉高度；它必须保留12px文字、键盘焦点和完整访问名称。独立网页或触控场景仍使用至少32px视觉高度或44px命中区。
- 错误不能只用红色表达，必须同时包含图标、文字说明和可执行建议。
- 动效必须支持 `prefers-reduced-motion`，减少动态效果时取消位移、旋转和循环动画。
