# 用对谈延伸新设计

## 设计不变量

- 内容和连续思考是中心，工具围绕内容出现；主操作应明确，次操作保持克制。
- 使用 --du-canvas / --du-surface、--du-text / --du-muted、--du-border 的中性层次；--du-accent 为主动作，--du-soft 为轻分组或选择背景，错误与成功保留语义。
- 正文与输入区轴线一致；--du-font、--du-font-size、--du-line-height 和 space 系列保持阅读节奏。--du-radius / --du-panel-radius 用于对应控件与容器，不给所有文本块套气泡。
- 内容、来源和工具分层；对话只是当前已有的一种组合，不是所有页面都必须采用的结构。

## 按任务选布局

| 用户任务 | 推导方式 |
| --- | --- |
| 连续对话 | 正文阅读列与输入区，只有需要跨会话管理时添加历史导航 |
| 搜索与研究 | 搜索为主入口，摘要、依据和结果按阅读顺序展开，相关问题作为辅助 |
| 写作、学习与偏好 | 需要对照时采用双区画布；单篇阅读或偏好可用居中单列与顶部分类 |

## 新组件的推导

以“来源引用列表”为例，这是项目本地组件，并非当前库导出。

1. 定义来源标题、出处、链接、引用位置和选择回调；链接只来自真实传入的数据。
2. 复用本套按钮、提示和容器，以正文/辅助字阶区分标题与出处。长内容直接展开在阅读面，不把每条来源做成大气泡。
3. 引用跳转有可访问名称；加载、暂不可用、重试各自表达，不编造书目、搜索结果或引用编号。
4. 窄屏按正文后的顺序显示，键盘能在引用与原文之间往返；浮层关闭恢复焦点。

## 跨业务示例

文档搜索网站可围绕搜索、答案与来源设计；学习工具可围绕题目、解释与追加问题设计。它们共享中性阅读、圆角输入与克制操作，无需出现会话侧栏或模拟聊天回复。

## 验收

解释主阅读轴与工具优先级，检查长中文、键盘、加载取消和错误恢复。新增本地组件可沿本套语言实现，但搜索、AI 回复、流式解析等服务与引擎须由项目接入，不虚构 Dialogue* 导出。
