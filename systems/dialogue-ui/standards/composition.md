# 组件与页面组合

## 内容与工具的关系

Message 与 Composer 是独立组件，可放入任意业务页面。ChatWorkspace 组合会话列表、正文阅读列和输入区；助手正文直接放在内容面上，用户消息采用浅灰气泡。

- 基础组件使用受控数据；会话与消息服务归接入项目所有。
- 正文列宽保持可阅读范围，输入区与正文轴线一致；工具不抢占正文标题层级。
- 低于 680px 的窄容器折叠会话导航，保留可见打开与关闭按钮；不宣称移动手势已实现。
- 页面属于 patterns；等待可停止，失败可重试，切换会话不能接收上一个请求的迟到正文。

## 扩展其他页面

研究或写作页可复用 Card、Tabs、Field、DropdownMenu 与 Dialog 管理来源和偏好。保持中性灰阶、圆角输入、克制操作区；无需把所有业务塞进对话窗口。
