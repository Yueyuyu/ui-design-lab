# 组件、页面与业务边界

## 页集工作台的层级

页面头、页面树、块编辑器、多视图数据库和记录详情属于业务组件；按钮、状态、提示、面包屑、视图标签属于基础组件；FolioWorkspace 是整页组合。

## 推荐的任务顺序

页面树选页 → 编辑内容块 → 在同一集合切换表格/看板/列表 → 侧开记录详情 → 保存或取消。记录数据共享，视图配置各自保留。

## 数据与服务范围

纯文本块不等于富文本引擎。无多人协作、评论、关系字段、公式和云权限。本地存储不提供多标签页并发合并。

## 验收一项组件

- 能从本套公开入口单独导入，不依赖 Gallery 或另一个套系。
- 有清楚的数据参数、事件回调和调用方责任；组件详情提供实际类型声明。
- 默认、悬停、按下、聚焦、禁用、加载、错误各有说明；不支持独立状态时明确由父流程承担。
- 以键盘和窄屏检查真实动作；截图只能确认布局，不能证明服务已经接通。
