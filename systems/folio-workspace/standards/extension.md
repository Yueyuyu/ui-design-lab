# 用页集工作台延伸新设计

## 设计不变量

- 页面、块与结构化记录共同表达内容，层级来自标题、缩进、留白与细线；正文不再套一层大卡片。
- 使用 --fw-paper、--fw-ink、--fw-muted、--fw-line 保持纸面关系；状态表面与文字采用本套配对变量，不能仅凭彩色装饰分组。
- 沿用 --fw-font、--fw-body-size、--fw-reading-width、--fw-radius 和 --fw-motion；阅读宽度与数据库宽度可不同。
- 同一集合的不同视图共享记录，视图设置独立。现有非模态详情保留列表上下文；未实现的业务能力不能从概念图推断。

## 按任务选布局

| 用户任务 | 推导方式 |
| --- | --- |
| 团队手册、知识入口 | 页面树仅在有层级内容时存在；浅层入口可用顶部索引与文档分组 |
| 项目手记、阅读与周计划 | 开放连续文档，标题、清单、批注按阅读顺序组织 |
| 研究集合与记录整理 | 全宽数据库，详情根据任务采用侧开或下方区域，不固定为三栏 |

## 新组件的推导

以“会议行动项清单”为例，这是可在项目中新增的组件，并非当前库导出。

1. 定义事项、负责人、截止日期、完成值与更新回调；正文会议记录和行动项通过稳定 ID 关联。
2. 复用合适的按钮、状态与提示能力，以轻行分隔和本套字阶实现清单，不把每一项做成指标卡。
3. 可采用语义化原生复选框作为新增结构，样式与焦点沿用本套规则；不能为补控件混入其他套系。
4. 保留草稿与错误恢复，明确已保存和未保存；窄屏将负责人、日期接在标题下，键盘顺序与阅读顺序一致。

## 跨业务示例

课程讲义可由连续阅读块与练习记录组成；项目主页可由背景、目标和行动项组成。它们不必使用页面树，也不因新增本地组件而具备富文本引擎、云协作或权限服务。

## 验收

新设计保持开放纸面、清晰块层级与记录关系。原包没有的评论、日历、关系字段可在项目扩展，但必须明确实现位置及数据契约，不能虚构 Folio* 导出。七态、中文输入、键盘与保存恢复按实际交互验证。
