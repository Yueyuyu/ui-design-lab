## Overview

Midnight Ledger 将深蓝画布、奶油色摘要、高密度数据区域和克制状态颜色组合成可长时间使用的复杂信息界面，适用于运营、监控、分析等业务。金融终端是当前应用示例：TradeGenius 主母版提供总览层级，紧凑母版补充表格与高频操作，CluesAI 驾驶舱补充多面板信息组织；这些场景不限定套系用途或导航形式。

## Colors

深蓝画布与略亮面板建立层级；奶油色既是主文字，也是高优先级摘要的反转表面。橙色用于主要操作，绿色和珊瑚红表达方向或结果，不能代表按钮层级。

## Typography

优先使用 Inter，中文回退至 Segoe UI Variable、Segoe UI、Microsoft YaHei UI。金额和关键收益采用粗体比例数字；ID、价格和时间可使用 Cascadia Mono。正文默认 14px，辅助文字不低于 11px。

## Layout

使用 4px 基准网格、12–16px 面板内边距和 8–12px 区域间距。多信号监控采用不等宽网格；记录处理可用全宽表格，复盘可用顺序阅读。窄屏按任务重排，关键摘要与主要操作先出现；导航取决于任务，不固定为侧栏。

## Elevation & Depth

依靠色阶与 1px 边线区分面板。阴影仅用于对话框和临时浮层，不使用玻璃模糊、霓虹光晕或渐变背景。

## Shapes

输入与按钮使用 6–10px 圆角，主面板使用 12px 圆角，语义标签使用胶囊。奶油资产面板的大圆角是套系签名，但不能复制到每个组件。

## Components

组件覆盖按钮、图标按钮、输入、选择器、开关、面板、状态标签、表格、对话框、通知、空状态、折线图、指标和终端预览。所有组件遵循 default、hover、pressed、focus、disabled、loading、error 七态。

## Do's and Don'ts

### Do

- 用连续表格和紧凑列表承载重复数据。
- 让奶油色资产面板成为少量高优先级反转表面。
- 用绿色与红色同时提供符号和文字，不只依赖颜色。
- 在小屏按任务优先级重排，而不是等比缩小。

### Don't

- 不把每个指标都做成独立卡片。
- 不使用赛博霓虹、渐变、玻璃拟态或大面积纯黑。
- 不把橙色同时当作品牌、警告和负收益颜色。
- 不从 Quiet Workspace 引入 Token、组件或资产。

## Responsive Behavior

多面板场景可从桌面 3–4 轨道收为平板 2 轨道、手机 1 轨道；单表或阅读场景按内容调整。表格在窄屏提供横向滚动并保留首列。图表保持最小 240px 高度，关键数据摘要始终位于首屏。

## Agent Usage

先读 `suite.json`、本文、`standards/extension.md`、`foundations/` 与相关标准，再读 API、类型和组件源码。使用 `[data-ui-system="midnight-ledger"]` 与 `--ml-*`，按需复用真实 `Ledger*` 导出，缺少时在业务项目内新增；不得混入其他套系。消费项目运行自身构建与交互检查，修改实验室时运行 `npm run suite:check`。

## 阅读层级与密度补充

金额、表格和持仓采用等宽数字对齐。紧凑模式收紧面板间距至 8px、持仓行至 52px，保留关键数字字号。长标识可换行，摘要与详情仍分层。

## 设计延伸

本套是一套可用于继续设计的视觉与交互语言，现有组件是可复用的起点。先读 [扩展规范](standards/extension.md)，根据任务选择布局，再决定直接复用、组合或在业务项目内新增组件。新增组件沿用本套 Token、字阶、间距、表面与交互规则，使用项目自己的名称和样式类；不能编造包导出，也不必复制示例页面的导航和业务字段。
