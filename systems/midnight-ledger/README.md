# Midnight Ledger / 午夜账盘

深色、高密度、金融终端式 UI 套系。视觉真相来自两张 TradeGenius 母版与 `references/midnight-ledger-live-source.png` 的 CluesAI 驾驶舱现场截图。

- 稳定 ID：`midnight-ledger`
- CSS 作用域：`[data-ui-system="midnight-ledger"]`
- Token 前缀：`--ml-`
- 组件前缀：`Ledger*` / `.ml-*`

两张母版属于同一视觉语言：主图定义资产总览、持仓、日历与图表；紧凑图定义交易操作、计划表单、持仓表和建议流。
