# Accessibility

- 正文与背景对比度至少 4.5:1；关键金额不得只靠红绿表达，必须同时显示正负号、文字或图标。
- 所有控件保留可见焦点环，焦点色为 `--ml-focus-ring`，不得被面板裁切。
- 表格使用 caption、th 与行级键盘激活；图表必须提供可读摘要和数据列表替代。
- 辅助文字不低于 11px，主要表单与正文不低于 12px。

## 模态对话框

使用 Portal 与原生 dialog.showModal()，在独立套系作用域中进入 top layer，避免长页面和带 transform 的父容器改变定位。打开时继承触发位置密度，聚焦关闭按钮，锁定背景滚动；Tab / Shift+Tab 仅在可用且非 inert 的控件间循环。Escape、背景和关闭按钮请求受控关闭，卸载时恢复滚动及仍在文档中的触发器焦点。

每个实例使用唯一标题与说明 ID。加载、禁用时内容和提交区不可交互，保留右上角关闭入口；错误时保留说明及恢复动作。长内容在视口内滚动，不裁切关闭入口。以上只处理 UI 生命周期，业务方负责异步请求取消和数据一致性。
