# 组件与页面组合

## 分组与主从关系

使用 NavigationList 表达分类选择。SettingsGroup 聚合同一目标的设置，SettingRow 保持标题、说明与控件的对应关系。桌面标签在左、操作在右；宽度小于 680px 时控件换至下一行，分类导航转为可换行按钮。

- 基础控件只执行一个动作或管理一个受控值，不持有业务请求。
- 分组标题在白色组表面之外，组内相邻行用轻分割线连接。
- 设置工作台属于 patterns；密度改变行距与控件高度，正文仍保持 14px。
- 保存回调由业务项目提供；失败保留草稿，取消恢复基线，刷新不承诺持久化。

## 扩展其他页面

资料页可组合 NavigationList、Card、Field 与 Dialog；保持蓝色用于当前项和主要动作，不为每个面板增加强调色。通过相同分组结构保持套系一致，业务内容与示例设置不绑定。
