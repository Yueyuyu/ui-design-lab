# 用果序延伸新设计

## 设计不变量

- 分组服务于同一个用户目标，标签、说明、当前值与动作保持直接对应，减少用户推断。
- 使用 --ou-canvas、--ou-surface、--ou-text、--ou-muted、--ou-border 的表面层级。--ou-accent 表示主要动作/当前选择，--ou-soft 为轻选择底色；功能图标色不能代替状态语义。
- 字体与控制密度沿 --ou-font、--ou-font-size、--ou-control-height、--ou-row-gap 及 space 系列。组与控件可有不同圆角，分别使用 --ou-panel-radius 与 --ou-radius。
- 继承分组、主从关系与直接反馈，不自行宣称 Apple 官方组件、原生平台功能或未实现的玻璃材质。

## 按任务选布局

| 用户任务 | 推导方式 |
| --- | --- |
| 多类偏好设置 | 分类导航配分组表面；类别少时顶部标签即可 |
| 文件、照片与资料 | 顶部工具栏、内容网格或列表，选中后就近查看详情 |
| 笔记、日程与个人工具 | 根据阅读或时间组织主区，不强制继承设置侧栏 |

## 新组件的推导

以“文件属性编辑组”为例，这是业务项目的本地组件，并非当前库导出。

1. 定义文件元数据、可编辑字段、草稿、保存/取消回调。下载与真实文件权限由项目服务处理。
2. 复用本套分组、设置行、输入与菜单能力，组标题放在组外；行内先标签后当前值与动作。
3. 文件图像与类型符号使用实际资源及已有图标接口；不能拿不相关品牌图标代替文件类型。
4. 保存失败保留草稿，成功后才刷新已保存值；窄屏控件转到标签下方，保留明确的保存和取消。

## 跨业务示例

个人资料站可采用顶部分类与文档集合；订阅管理页可采用分组条目和明细。延续清楚的分组、选择与反馈即可，不必复制系统设置应用。

## 验收

验证分组是否符合用户目标、操作是否在对象旁、说明是否与控件关联。新增本地组件保留本套七态、键盘与密度，不冒充 Orchard* 导出；品牌主题在业务层管理，保证强调色对比度与状态区分。
