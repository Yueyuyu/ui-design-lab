# 用信号创作间延伸新设计

## 设计不变量

- 内容本身建立吸引力：标题、真实图像、摘要和阅读顺序共同组织层级，工具保持次要。
- --ss-canvas / --ss-surface 表达暖纸背景，--ss-text / --ss-muted 承载内容，--ss-brand 用于链接和主动作，--ss-negative 用于错误。
- 叙事标题使用 --ss-heading，正文和控件使用 --ss-font；不能把表单标签全部改为大衬线字。间距、控件、行高、形状与反馈沿用本套 Token。
- 内容区面积按主次分配，可以不等宽；不要把所有内容机械排成等面积卡片。

## 按任务选布局

| 用户任务 | 推导方式 |
| --- | --- |
| 公开阅读、品牌内容网站 | 顶部导航、主文章/主图与次内容分组，不强加编辑器或后台菜单 |
| 编辑文章或课程内容 | 正文画布与就近工具，只有同时对照时才采用双区 |
| 素材浏览、排期与作品集 | 开放素材墙、横向时间线或叙事序列，选择后出现相关动作 |

## 新组件的推导

以“文章目录与阅读进度”为例，这是项目本地组件，并非当前库导出。

1. 定义章节、当前章节、阅读进度与跳转回调；章节标题仍可通过正文阅读。
2. 使用本套正文/辅助字阶与细分隔，主标题保留衬线，跳转采用品牌色和清楚的聚焦状态。
3. 目录为辅助导航：宽屏可放页边，窄屏收为可展开区域；没有长文结构时不显示空目录。
4. 键盘可跳到章节，目标标题可获得焦点；低动态偏好取消平滑滚动，不制造无意义的加载状态。

## 跨业务示例

独立杂志可从故事主次推导开放首页；在线课程可从章节与练习推导阅读编辑页。保留暖纸、衬线层级和内容节奏，而不是复制现有“主封面加两张侧图”的固定版式。

## 验收

每张图和每一层标题都应有内容目的。新增上传、素材库或发布功能须由项目实现并验证，不能把设计稿当作已支持 API；复用现有接口时查看实际类型，新组件补齐适用七态与阅读可访问性。
