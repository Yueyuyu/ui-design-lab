# 可访问性

- 正文与背景的对比度目标为 4.5:1；状态同时提供文字，不能只变颜色。
- 输入框有标签，分组控件有 legend，错误通过 aria-invalid 和邻近说明表达。
- 标签页保留当前状态；表格的搜索、排序、选择与分页都能通过键盘操作。
- 抽屉进入模态层并约束焦点；Escape 和关闭按钮退出，焦点恢复触发器。加载时保留关闭入口。
- 390px 手机下按任务顺序排布；宽表允许内部滚动，外部页面不应横向溢出。

## 需要真实产品补齐的验证

本套仅提供界面行为。接入后还需要检查实际错误消息、长文本、放大阅读、读屏软件和异步请求取消；不以截图或构建结果声称完整 WCAG 合规。
