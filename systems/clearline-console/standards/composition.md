# 组件、页面与业务边界

## 澄明后台的层级

项目目录和项目详情是两个业务组件。前者组合数据表格和项目列，后者组合标签页和项目属性；两者由工作台持有同一份项目数据。

## 推荐的任务顺序

搜索与选择项目 → 在右侧查看 → 修改状态 → 回写原记录。不能复制出另一份互不更新的详情数据。

## 数据与服务范围

项目工作台支持受控数据与异步保存适配器，默认仅保存内存示例；权限控制、团队资料、审计历史和服务器保存由接入项目提供。Activity 当前是记录摘要，不是完整审计轨迹。

## 验收一项组件

- 能从本套公开入口单独导入，不依赖 Gallery 或另一个套系。
- 有清楚的数据参数、事件回调和调用方责任；组件详情提供实际类型声明。
- 默认、悬停、按下、聚焦、禁用、加载、错误各有说明；不支持独立状态时明确由父流程承担。
- 以键盘和窄屏检查真实动作；截图只能确认布局，不能证明服务已经接通。

## 失败恢复

保存失败时保留草稿与旧集合，提供重新保存；成功回调后更新集合。关闭/取消/卸载发送取消信号，忽略迟到成功；服务端可能已写入，消费项目需重新读取真值。切换工作区用 React key。
