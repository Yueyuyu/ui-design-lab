# 状态与反馈

组件详情逐项展示 foundations/interaction-states.json 的七态。七态合同说明职责，并不表示每个组件都接受七个同名参数。

- 表单控件通过 value/checked 与 onChange 保持受控；加载时禁用重复操作，错误时保留值。
- 抽屉通过 open/onOpenChange 管理生命周期，保存、取消和关闭的业务语义由父页面决定。
- 静态标签、内容容器不应伪装成按钮。它们的加载和错误通常由所属页面负责。
- 数据表格与图表明确支持加载、失败和空数据，重试需要调用方提供回调。
- 悬停不是唯一入口；需要操作的内容在键盘聚焦时也必须可理解和可使用。
