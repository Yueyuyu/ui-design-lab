DataTable 为客户端分页；远程接口由调用方提供。日期为本地日历字符串。套系提供浅色与两档密度，不暗示支持深色。

DataTable 列 render(value, row) 接收单元格值与整行；它与早期静态 Table 的行渲染约定分开。菜单、Popover 和 Tooltip 使用原生 popover 顶层；目标浏览器须支持 Popover API。
