# 用脉点桌面延伸新设计

## 设计不变量

- 脉点目前是 draft 的黑色桌面状态语言：轻量常驻、需要时展开、不妨碍用户原任务。现有额度环、浮条、指向面板沿用既有造型，不在扩展时重新改画。
- 使用 --pd-surface、--pd-ink、--pd-muted、--pd-line、--pd-track 和已定义的状态颜色。额度色、任务状态与服务连接状态各有意义，不能合并为一个“健康”色。
- 字体、控制、留白和反馈沿 --pd-font、--pd-text、--pd-caption、--pd-control、--pd-inset、--pd-enter、--pd-exit。面板文字保持可读，背景环境不属于产品 Token。
- 上游资源与许可遵循 UPSTREAM.md；未知数值不填示例，第三方机器人不能因新增页面而获得公开分发权。

## 按任务选布局

| 用户任务 | 推导方式 |
| --- | --- |
| 被动查看状态 | 保留紧凑环与数字，让详细信息按需出现 |
| 查看任务或执行少量操作 | 在现有面板内按身份、额度、关注、其他内容分区 |
| 配套状态页或详细记录 | 可以在项目中设计更完整的页面，但需另行定义阅读、导航和窄屏方案；不能把浮条等比放大成网站布局 |

## 新组件的推导

以“连接状态行”为例，这是项目可新增的局部组件，并非新的公开 Pulse* 导出。

1. 明确来源、读取状态、上次成功时间、停止与重试回调；任务与额度各自传入状态。
2. 在既有黑色面板语言中排布短标签、说明和就近恢复动作；不能用任务进度环代替连接状态。
3. 读取失败保留已知来源和恢复入口，缓存必须标明；无数据不伪造额度或任务。
4. 操作通过宿主回调，组件不自行读取令牌或其他应用数据；键盘焦点、临时展开与固定逻辑保持既有约定。

## 跨业务示例

构建状态、同步状态等可作为项目自己的只读状态面板，沿用少干扰、按需展开和明确来源的原则。现阶段不能声称已有完整网站或原生移动体系；需要的页面可以继续设计，但须作为新适配验证。

## 验收

本套尚无公开组件包入口，先在实验室或明确的本地适配中使用。保持原浮条/面板和 320ms 离开宽限、低动态及卸载清理约定。新增项目组件单独说明数据责任、七态、键盘与宿主行为，不改变组件成熟度或账户接入声明。
