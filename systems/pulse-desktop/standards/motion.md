# Pulse 动效移植

沿用 BotMarkChoreography 的完整 8 人格顺序与 hold 区间，原始 SVG/物理/变形/粒子由同源引擎运行。工作、读取、待命、不可用、用尽分别映射上游状态；任务新完成使用各人格 completion，2600ms 后回到当前业务状态，首连/重连不补播。

遵照用户“直接沿用”优先于 animate 技能中的自建曲线建议。技能仅用于生命周期、可中断、静态及低动态验证：
- CardReveal：原版 spring response=.34 / damping=.82，.88→1 scale、10px→0 位移，Web Animations 采样，600ms 覆盖弹簧收敛。
- 悬停离开宽限 320ms；拖动即时跟随，不添加惯性。
- 当前面板进入复用 CardReveal；关闭立即生效，尚未实现 SwiftUI 完整退出/连续 berth 变形过渡，不将其宣称为逐帧完整移植。
- 机器人最多 30fps。不可见、系统低动态或用户停用时取消帧；卸载释放引擎、观察器、媒体监听。
- 静态模式模拟 3s 以稳定表情并避开闭眼首帧。任务读数不随机器人形变；无原版资源时显示明确的静态品牌图标，不静默改画替身。

Windows 使用同一 renderer；WebView2 不重编一套动画。
