# UI Design Lab 1.0.0-beta.1

2026-09-06，本地 Beta 候选。包保持 private，未创建公开 Release、Tag 或 npm 版本。

## 本版本提供什么

- 四套独立视觉系统，以及任务与用量、研究与内容、运营报表三个连续 UI 场景。
- 统一首页封面、套系目录、同场景比较、主题编辑与 API 上下文。
- 每套一个独立 Starter，vendor/ 自带 ESM 组件包，跨目录和跨机器无需原仓库绝对路径。
- Node.js 22+、React 19.2、类型声明与公开套系子路径；现有代码、规范及本次示例沿用 MIT。

## 本次收尾

- 补齐网站接入步骤与下载指南：安装依赖、构建组件包、生成项目、启动、修改数据、验证构建。
- 安装文案随 package.json 版本生成，避免发布后复制到旧版文件名。
- 修复较短 A/B 画布使页面底部滚动位置跳动的问题，保持套系组件原有高度。
- 增加文件选择器、重复选择、拒绝文件、拖放事件、取消与迟到成功回归；补充跨引擎与窄屏验收。
- 增加候选产物生成脚本、版本清单和 SHA-256 校验，提供真实试用和固定范围服务记录模板。

## 试用须知

- Quiet Workspace 为 stable 套系；其他三套维持 experimental。Gallery 的 Beta 通道不替代套系各自成熟度。
- 登录、原文件存储、任务服务、模型、支付与邮件未接生产后端；当前业务数据为明确的本地模拟。
- 精确的执行结果和覆盖边界见仓库 docs/ACCEPTANCE.md 与 COMPATIBILITY.md。
- WebKit 自动化引擎不等于 Safari 实机；文件选择器事件和合成 DataTransfer 不等于人工操作 Windows 文件对话框或从资源管理器拖入文件。
- 第三方参考图片受 NOTICE.md 单独约束，不随组件包交付。

反馈时请提供版本、套系、浏览器、复现步骤与预期结果；不要提交密钥、生产数据或私人文件。试用指南见 BETA-TRIAL.md。
