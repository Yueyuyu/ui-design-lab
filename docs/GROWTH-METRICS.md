# 最小增长口径
网站实现显式开启的本地事件记录，保留最近500条；不上传服务器，不记录业务文本、邮箱、文件名、Token 或主题内容。

| 事件 | 触发 | 可得结论 |
|---|---|---|
| catalog_view | 首页目录挂载 | 一次浏览事件，不代表 UV |
| suite_open | 从目录进入套系 | 发生选型查看 |
| kit_view | 点击流程预览 | 对场景有兴趣 |
| onboarding_start | 下载接入说明 | 开始尝试接入 |
| instruction_copy | 完成指令复制 | 复制行为，不能当接入 |
| theme_export | 生成主题配置 | 主题导出行为 |
| consumer_verified | 外部项目实际安装/运行证据，线下记录 | 初次运行成功 |
| repeat_usage | 同一外部项目在后续工作中继续使用，线下反馈 | 持续使用 |
| purchase | 支付服务端确认订单，未来接入 | 实际购买 |

服务端事件暂未接入。当前 UI 不显示虚构漏斗数字。访问 UV、留存、购买转化需在部署后定义匿名会话、去重、时区和同意机制。

手工接入证据表：项目匿名ID、日期、套系/包版本、安装命令结果、实际渲染页面、失败步骤、支持耗时、是否继续使用、公开案例许可。成功构建与真实使用分列。Stars、复制、下载不合并计算激活。主题 JSON/CSS 导出、比较指令复制均已接入 recordEvent 白名单；本地事件不等于线上分析服务。
