# 远期候选与进入条件
| 候选 | 进入条件 | 最小验证 |
|---|---|---|
| L01 团队订阅 / 私有套系 | 至少数个团队重复提出版本共享和维护需求 | 先做手工私有交付与支持成本记录，再做账号/RBAC |
| L02 AI 一致性检查 | 有真实新增页面与纠错样本 | 先复用 Token/隔离静态规则，报告具体代码证据 |
| L03 AI 主题生成 | 手动主题编辑、导入导出和对比度检查稳定 | 生成只输出白名单 JSON，经验证后预览 |
| L04 Figma 资产 | 设计师客户愿意使用且有维护预算 | 单套组件资产与代码版本对应，暂不做双向平台 |
| L05 套系市场 | 官方套系有稳定使用、作者供给与审核能力 | 投稿清单、来源许可和人工审核；分成后置 |
| L06 可视化搭建器 | 有持续拖拽编排需求和明确付费意愿 | 先测固定页面组合，单独评估维护成本 |
| L07 赞助与广告 | 有真实稳定访问与合适赞助方 | 明确标注赞助，不影响核心使用与独立评价 |

这些仍是候选方向，不为了勾选制造账号、市场或生成器空壳。本轮已完成依赖与进入条件整理。
