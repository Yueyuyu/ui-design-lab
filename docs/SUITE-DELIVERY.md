# 新套系交付合同
版本：2026-09-05。适用于本次四套及后续新增。

1. 明确独立用户场景与视觉语言，先记录选定视觉来源和布局尺寸。明暗模式或主题改色不算新套系。
2. 使用稳定 ID、唯一 CSS / Token 前缀、组件名称前缀；从 draft 开始。
3. suite.json 提供版本、成熟度、适用任务、局限、比较能力、主题控制与公开组件。首页最多两套精选，全量目录包含全部。
4. 首页 cover/index.jsx 使用统一 800 × 400 的同场景真实组件。公共标题 13–14px，封面约 200px；不能另行放大某套。参考母版只放来源说明。
5. 提供 DESIGN.md、JSON/CSS Token 双向绑定、七态合同、规范、组件导出、类型、API。新能力同时进入元数据、文档和可操作展示。
6. 七个标准栏目必须存在；业务组件、工作流、主题可以加独立入口。比较提供五类场景、四类模块；不支持时显式标注。
7. 所有源码只依赖本套系。共享 Gallery 业务场景可以传入套系渲染器，不能通过另一个套系伪装能力。
8. 运行 suite:check、Node 测试、类型、组件包与网站构建、Sites 测试；外部消费者安装各套导出；浏览器检查真实流程与断点。
9. 通过上述本地检查后仅升级 experimental。稳定发布需兼容承诺、迁移记录与实际采用证据。

本次选稿：Clearline Console 的表格 / 侧向详情；Signal Studio 的横向导航 / 衬线内容画布。Harbor Desk 保留为未实施候选，不新增第五套。


## 封面再生成

统一画布 800×400、compact 密度，同一项目概览/图表/表单数据。首页等比缩放并居中；母版仅放来源说明。内置浏览器打开 `#cover/<suite-id>` 可捕获完整画布；自动方式 `npm run covers`（先启动本地服务且安装 Playwright Chromium）。PNG 保存到 references/thumbnails，并更新 manifest；不要在日常测试中隐式重写素材。
