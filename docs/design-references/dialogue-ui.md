# Dialogue UI · ChatGPT 设计参考

采集日期：2026-09-18。套系为自主 Web 实现，非 OpenAI 官方组件库。

## 已查看来源

https://chatgpt.com/ 的未登录公开界面与设置界面。没有发送消息、登录账户或读取私人会话。浏览器截图为 references/dialogue-ui-source.png 与 dialogue-ui-settings-source.png。

## 页面观察

左侧为轻量导航，主内容留出阅读空间，欢迎语与圆角输入区成为视觉中心。工具图标体积小，主要发送动作使用圆形强调。设置按标签与当前值排列。以上是该次页面观察，不是 OpenAI 发布的官方 Token 或组件规范。

## 本项目适配

将输入、消息、话题建议与会话列表拆为公开组件，再与按钮、字段、开关、标签页、菜单和弹窗组成完整套系。使用原创名称和文案，不分发 OpenAI 标识。初始页面使用适合组件演示的三条话题建议，已填充对话样式为本项目扩展。

默认回复有明确的本地演示说明；异步 onSend 由消费项目接入。支持中文组合输入、发送、停止、重试和会话切换。首版仅接收完整纯文本回复，不声称提供模型服务、流式协议、Markdown 渲染、云历史、文件上传服务或认证。
